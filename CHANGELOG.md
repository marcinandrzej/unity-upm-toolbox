# Changelog
All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## [1.5.0] - 2026-11-10
### Added
- Scenes system abstractions and generics, along with sample.

## [1.4.0] - 2026-11-09
### Added
- Settings system abstraction and generics.
- Player input system abstraction and generics.
- Transition system abstraction and generics.

## [1.3.0] - 2026-11-09
### Changed
- Serializer architecture base changed to ScriptableObject.
### Added
- Serialization exception handling.
- Save system abstraction and generics.

## [1.2.0] - 2026-11-05
### Added
- Serializer interface with two implementations: JSON and encrypted JSON. 

## [1.1.0] - 2026-11-05
### Added
- Singleton pattern.
- Service locator pattern.

## [1.0.0] - 2026-11-03
