### Update
- [Scenes system] Scenes system refactor.

- [Scenes system] Build in and addressable based loaders added.

## [1.5.0] - 2026-11-10
### Added

## [1.4.0] - 2026-11-09
### Added
- [Settings system] Settings system abstraction and generics.
- [Input system] Player input system abstraction and generics.

### Added
